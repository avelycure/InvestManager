# Формат входных Markdown-файлов

В настройках плагина пользователь выбирает четыре файла из своего хранилища Obsidian. Имена и расположение файлов произвольные. Примеры ниже показывают структуру; содержимое строк пользователь заменяет своими данными.

Кнопка **Инициализировать** в настройках создаёт недостающие файлы `Компании в портфеле.md`, `Темы новостей.md`, `Telegram каналы.md`, `Издания.md` в папке `Статистика`, затем указывает их в настройках плагина. Существующие файлы с такими именами не перезаписываются. После инициализации замените примерные записи своими данными. Ранее созданный файл `Финансовые показатели.md` остаётся в хранилище, но плагин больше его не читает.

Компании и издания задаются Markdown-таблицами с заголовком и разделителем `| --- |`: для них в каждой записи нужны несколько полей. Темы и Telegram-каналы можно задать такой таблицей либо простым нумерованным или маркированным списком. Пустые строки и обычный текст вне таблицы или списка игнорируются. Названия столбцов должны совпадать с примерами; порядок столбцов может меняться. Плагин сообщает имя файла и номер строки при ошибке, а повторные тикеры, каналы и адреса изданий считает ошибкой. Дополнительные столбцы допустимы, но не используются, пока их поддержка не описана отдельно. Начальные шаблоны доступны через кнопку **Формат файлов** в настройках плагина. Кнопка **Скопировать шаблон** помещает Markdown в буфер обмена; затем его можно вставить в нужную заметку и заменить примерные значения.

## Компании портфеля

В этот файл входят только компании, которыми пользователь владеет. Обязательны `Название` и `Тикер` на Московской бирже. Необязательная колонка `Цвет` задаёт цвет карточки по логотипу компании шестизначным кодом `#RRGGBB` (например, `#21A038` для Сбера). Без неё для SBER, LKOH, SIBN, PHOR, ROSN, PLZL, MOEX, BELU и MDMG используются предзаданные оттенки; для остальных компаний — общий акцент темы. Любой предзаданный оттенок можно заменить через колонку `Цвет`. Колонка `Инвесторам` сохранена для возможного возврата раздела МСФО, сейчас она не используется. Один ряд — одна компания. В старых таблицах колонка `Сайт` допускается, но не используется.

По колонке `Тикер` в блоке компании строится график цены акции Мосбиржи и показывается капитализация её выпуска. Кнопки в заметке переключают последний торговый день, неделю, две недели, месяц и год; для работы переключателя плагин должен быть включён.

```md
| Название | Тикер | Цвет | Инвесторам | Пресс центр компании |
| --- | --- | --- | --- | --- |
| Сбер | SBER | #21A038 | https://example.com/investors | https://example.com/news |
```

## Темы

Обязательна `Тема`. `Ключевые слова` содержат русские формы и синонимы, `Английские варианты` — переводы для иностранных лент. Несколько слов или фраз разделяются точкой с запятой. Название темы тоже участвует в поиске. При подключённой модели плагин дополнительно проверяет публикации без дословного совпадения на смысловую близость к темам. Без модели работают только перечисленные варианты. Для новых тем добавьте английские варианты в файл, если они нужны.

```md
| Тема | Ключевые слова | Английские варианты |
| --- | --- | --- |
| Инфляция | инфляции; потребительские цены | inflation; consumer price index; CPI |
```

Для простого списка достаточно `1. Ключевая ставка США` или `- Ключевая ставка США`.

## Публичные Telegram-каналы

Обязательны `Название` и `Канал`. В `Канал` указывается публичный `@username` или `https://t.me/username`. Числовой ID не требуется. Доступность канала проверяется выбранным поставщиком данных.

```md
| Название | Канал |
| --- | --- |
| Название канала | @example_channel |
```

Для простого списка достаточно `1. @example_channel`; название тогда совпадает с `@username`.

## RSS-ленты изданий

Обязательны `Название` издания и `RSS-лента` — прямой URL его RSS/Atom-ленты. Адрес главной страницы здесь не нужен. Старое название колонки `Адрес` продолжает читаться для совместимости с уже заполненными файлами.

```md
| Название | RSS-лента |
| --- | --- |
| Название издания | https://example.com/feed |
```
