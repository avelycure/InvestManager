# Ревью базовой версии · 18 октября 2026

Проверены сборка плагина, тесты, конфигурация CI, запись в хранилище Obsidian, сбор и отбор новостей, графики, расписание и сохранение отчёта. Перед фиксацией базовой версии исправлены следующие дефекты.

| Область | Исправление |
| --- | --- |
| Расписание | Запуск в заданное время больше не задерживается ограничением повторов после подготовки. При обычном утреннем запуске конец окна фиксирован на заданном времени, даже если подготовка не удалась. |
| Графики | Графики акций в старых заметках привязаны ко времени отчёта и не меняются при открытии спустя дни. |
| Новости | Прочитанные и исключённые публикации убираются до заполнения квот историческими новостями. RSS-ленты одного издания имеют раздельную историю. Упоминание компании только в описании чужой новости не считается новостью этой компании. |
| Даты | Публикация пресс-центра с датой без времени попадает в 24-часовой интервал только тогда, когда весь указанный календарный день входит в него. |
| Данные | Снимок последней сводки перенесён из настроек Obsidian в `Статистика/.invest-manager/last-digest.json`; старые данные мигрируют при запуске. Для адресов источников отклоняются локальные и частные IP-адреса. |
| Проверки | В CI добавлен запуск тестов. |

Проверки базовой версии: `npm run build`, `npm test` (89 тестов), `npm run lint` (ошибок нет, 24 предупреждения), `npm audit --omit=dev` (уязвимостей нет), `git diff --check`. Миграция снимка отдельно проверена на установленном плагине в Obsidian.

Оставшиеся ограничения:

- Проставление оценок и отметки «прочитано» доступно во вкладке Invest Manager; в самой Markdown-заметке интерактивных кнопок оценки нет.
- Проверка адреса источника не контролирует DNS-ответы и перенаправления после исходного запроса. Для полной защиты от обращения к внутренним адресам через внешний домен понадобится сетевой слой с проверкой каждого перехода.
- Полнота 24-часовой истории зависит от доступности и глубины выдачи внешних RSS, пресс-центров и Telegram; неполный охват показывается в отчёте.
